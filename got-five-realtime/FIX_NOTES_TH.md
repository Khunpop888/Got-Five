# GOT FIVE! - Full Game Audio System (v6)

อัปเดตวันที่ 13 สิงหาคม 2026

## สิ่งที่แก้ไข

- Private Board ตอบสนองทันทีเมื่อกดตัดหรือคืนเลข โดยไม่สร้างหน้าเกมใหม่ทั้งหมด
- Server ตอบกลับการตัดเลขด้วย message ขนาดเล็กเฉพาะสถานะที่เปลี่ยน
- Heartbeat ใช้ `ping`/`pong` ขนาดเล็ก แทนการส่ง state ทั้งห้องทุก 25 วินาที
- ข้ามการ render เมื่อได้รับ state sync ที่ revision ไม่เปลี่ยน
- เปลี่ยนสถานะเลขที่ตัดให้เป็นพื้นมืดพร้อมเครื่องหมาย X สีแดงที่เห็นชัด
- ลด shadow, filter, backdrop และ animation ที่สร้างภาระบนหน้าจอขนาดเล็ก
- เลขทดบนไทล์ลับแยกตามเวลาเริ่มแมตช์ จึงยังอยู่ระหว่างแมตช์เดิม แต่เริ่มว่างเมื่อขึ้นแมตช์ใหม่
- เพิ่ม cache-busting version สำหรับ `app.js` และ `styles.css`
- ลดข้อมูล real-time ที่ส่งซ้ำ: log สดเหลือ 30 รายการ, chat 50 รายการ และไม่แนบรูปโปรไฟล์ base64 ซ้ำในทุก log/chat
- ไม่ส่งประวัติแมตช์เก่าทั้งชุดระหว่างกำลังเล่น เพื่อลดขนาด message และงาน parse/render ฝั่ง browser
- รวมการ render state หลาย message ให้อยู่ใน animation frame เดียว และแสดง Game Log ล่าสุดไม่เกิน 24 รายการ
- เปลี่ยนเลขที่ตัดบน Private Board เป็นพื้นดำทึบ ตัวเลข/จุดจาง และมีแถบสีเดิมด้านซ้ายเพื่อยังบอกสีได้
- บนจอ Desktop ปรับ Step 1 และ Step 2 ให้สูงเท่ากัน 168px พร้อมดันแท่นวางขึ้นมาจบพอดีขอบจอโดยไม่ต้องเลื่อนหน้า
- เพิ่มข้อมูลรอบที่กดทายในสถิติผู้เล่น การ์ดอันดับชั่วคราว และคอลัมน์ `รอบที่ทาย` ในตารางก่อนเกมถัดไป
- เพิ่ม cache-busting รอบใหม่เป็น `20260813-layout-performance-v2`
- เพิ่ม Turn Guide ที่แจ้งชัดว่าเป็น `STEP 1/2` หรือ `STEP 2/2` พร้อมบอกสิ่งที่ต้องทำในแถบตาปัจจุบัน
- ไฮไลต์กรอบ Step ที่ต้องทำด้วยสีเหลืองและป้าย `ทำขั้นตอนนี้ตอนนี้`; เมื่อจั่วแล้ว Step 1 เปลี่ยนเป็น `✓ จั่วแล้ว`
- Compare เปิดโหมด Spotlight พื้นหลังทึบ แสดงไทล์กลางที่เลือกและคำอธิบายว่าต้องเลือกไทล์บนแท่นของตนเอง 1 ใบ
- ในโหมด Compare แท่นของผู้เล่นสว่างขึ้น ไทล์ลับทั้ง 5 ใบมีกรอบเหลืองและป้าย `ใบที่ 1–5` พร้อมปุ่ม `ยกเลิก Compare` ขนาดใหญ่
- รองรับการเลือกไทล์ Compare ด้วยเมาส์ สัมผัส และปุ่ม Enter/Space
- Categorise แสดงหน้าต่างยืนยันพร้อมภาพไทล์และแท่นตัวอย่างก่อนส่งคำสั่งจริง ป้องกันการกดพลาด
- การยกเลิก Compare หรือ Categorise จะไม่ล้างไทล์กลางที่เลือก จึงกลับไปตัดสินใจใหม่ได้ทันที
- เพิ่ม cache-busting รอบใหม่เป็น `20260813-guided-actions-v3`
- ทำ Active Step ให้เด่นขึ้นด้วยกรอบแดงหนา วงเรืองสีเหลือง หัวกรอบสีเข้ม และป้ายแดง `▶ ทำ STEP 1/2 ตอนนี้`
- เปลี่ยนข้อความป้ายให้ระบุเลข Step โดยตรง แทนข้อความทั่วไปที่มองผ่านได้ง่าย
- จัด Step 2 บน Desktop เป็นแถว Header / ไทล์กลาง / ปุ่มคำใบ้ที่มีความสูงแน่นอนภายในกรอบ 168px
- ลดพื้นที่ไทล์กลางเฉพาะ Desktop อย่างพอดี และกำหนดปุ่ม Categorise/Compare สูง 34px เพื่อให้เห็นครบทั้งปุ่ม
- คงความสูง Step 1 และ Step 2 เท่ากัน รวมถึงไม่ดันแท่นวางหลุดจากขอบจอ
- เพิ่ม cache-busting รอบใหม่เป็น `20260813-active-step-layout-v4`
- เปลี่ยนส่วน `ตารางคะแนนชั่วคราว` เป็น `ตารางคะแนนรอบปัจจุบัน` ซึ่งแสดงผลเฉพาะเกมย่อยที่เพิ่งจบ ไม่ปะปนกับคะแนนสะสม
- การ์ดอันดับเกมปัจจุบันแสดงอันดับ สถานะผู้เล่น แต้มที่ได้ในเกมนั้น และรอบที่กดทาย
- เพิ่มตาราง `อันดับรายเกม` แยกคอลัมน์เกม 1–5 เพื่อดูว่าแต่ละเกมย่อยผู้เล่นได้อันดับใด ได้กี่แต้ม และเกมใดยังรอแข่ง
- เปลี่ยนชื่อตารางสะสมเป็น `ตารางคะแนนรวมทุกเกม` พร้อมระบุจำนวนเกมที่รวมผลแล้วอย่างชัดเจน
- หน้า Final แสดงทั้งรางวัลรวม อันดับเกมสุดท้าย อันดับรายเกม และตารางคะแนนรวม โดยแต่ละส่วนใช้ข้อมูลคนละระดับ
- ปรับตารางอันดับรายเกมให้เลื่อนภายในกรอบบนมือถือ โดยไม่ทำให้ทั้งหน้าล้นแนวนอน
- เพิ่ม cache-busting รอบใหม่เป็น `20260813-match-scoreboards-v5`
- เพิ่มระบบเสียงเกมด้วย Web Audio API โดยไม่เพิ่มไลบรารีหรือไฟล์เสียงภายนอก จึงยังคงใช้ Python Standard Library เท่านั้น
- เพิ่มเสียงตอบสนองสำหรับปุ่มทั่วไป การเลือกสี/ไทล์ การเปิด Popup การยืนยัน การยกเลิก และการส่งแชท
- เพิ่มเสียงเฉพาะสำหรับตัด/คืนเลขบน Private Board, จั่วไทล์, Categorise และ Compare โดย Compare แยกเสียงคำตอบ `ใช่` กับ `ไม่ใช่`
- เพิ่มเสียงแจ้งเมื่อถึงตาผู้เล่น เมื่อเปลี่ยนจาก Step 1 ไป Step 2 และเมื่อเริ่มเกมย่อยใหม่
- เพิ่มเสียงก่อนส่งคำตอบ GOT FIVE, เสียงทายถูก, เสียงทายผิด, แฟนแฟร์จบรอบย่อย และแฟนแฟร์ใหญ่เมื่อจบซีรีส์
- ส่งเหตุการณ์เสียงผล GOT FIVE ผ่าน Server ให้ผู้เล่นทุกคนได้รับพร้อม State เดียวกัน
- Bot ส่งชุดเหตุการณ์เสียงเรียงลำดับสำหรับทั้งการจั่วและขอคำใบ้ รวมถึงตอน Bot ประกาศ GOT FIVE
- เพิ่มเสียงผู้เล่นเข้าห้อง ข้อความแชทใหม่ และข้อความผิดพลาด
- เพิ่มปุ่ม `เสียง: เปิด/ปิด` แบบลอย จดจำการตั้งค่าด้วย Local Storage และย่อเป็นไอคอนบนมือถือ
- เพิ่ม cache-busting รอบใหม่เป็น `20260813-full-game-audio-v6`

## การตรวจสอบ

- Python unit tests: 23 tests ผ่านทั้งหมด
- JavaScript syntax check: ผ่าน
- Browser test: ทดสอบตัดเลขแบบ optimistic, สีพื้นดำ, ตัวนับ Private Board, หน้าเล่นจริง 4 คน และตารางสรุปหลังเกม
- Desktop layout test: viewport 1900 x 850 ไม่มี page scroll, Step 1/2 สูงเท่ากัน และแท่นวางอยู่ครบภายในจอ
- Browser console: ไม่พบ error หรือ warning
- Payload test: ยืนยันว่า state สดไม่แนบ avatar ซ้ำและมีขนาดต่ำกว่า 80 KB ในกรณีทดสอบรูปโปรไฟล์ขนาดใหญ่
- Guided flow test: ตรวจข้อความ Step 1 ก่อนจั่วและเปลี่ยนเป็น Step 2 หลังจั่วจริง
- Compare test: ตรวจ Spotlight, ปุ่มยกเลิก, การคงไทล์ที่เลือก และการส่ง Compare หลังเลือกไทล์ลับเท่านั้น
- Categorise test: ยืนยันว่าการเปิด popup ยังไม่ส่ง action และส่งเมื่อกดปุ่มยืนยันเท่านั้น
- Mobile test: viewport 390 x 844, Compare เลื่อนไปหาแท่นอัตโนมัติและไม่มี horizontal page overflow
- Desktop layout test: viewport 1900 x 850 ยืนยันว่าปุ่ม Categorise/Compare อยู่ภายในกรอบ Step 2 ทั้งหมด และหน้าไม่มี vertical scroll
- Mobile layout test: viewport 390 x 844 ยืนยันว่า Active Step แสดงเป็นหัวกรอบสองแถวและไม่มี horizontal overflow
- Series summary test: ทดสอบจริงครบ 3 เกม ยืนยันว่าเกมที่เล่นแล้วมีอันดับ/แต้มครบ เกมที่ยังไม่เล่นแสดง `รอแข่ง` และเมื่อจบซีรีส์ไม่มีช่องค้าง
- Current-match test: ยืนยันว่าการ์ดด้านบนเปลี่ยนตามเกมล่าสุดและไม่ใช้ค่าชนะ/คะแนนสะสมจากตารางรวม
- Mobile post-match test: viewport 390 x 844 ไม่มี horizontal page overflow และตารางอันดับรายเกมเลื่อนภายในกรอบได้
- Browser console: ไม่พบ error หรือ warning หลังเล่นครบ 3 เกม
- Python unit tests: 25 tests ผ่านทั้งหมด รวมการส่งเสียงผล GOT FIVE และชุดเสียงสองแอคชั่นของ Bot
- Audio interaction test: ยืนยันว่าเสียงถูกปลดล็อกหลัง user interaction ปุ่มเปิด/ปิดเปลี่ยนสถานะและมี accessibility label ถูกต้อง
- Full action audio test: ทดสอบกดปุ่ม ตัดเลข จั่ว Categorise Compare ทายผิด จบรอบย่อย และจบซีรีส์จริง
- Bot audio batch test: ยืนยันจาก Game Log ว่า Bot จั่วและ Compare ต่อกัน พร้อม client ประมวลผลชุดเหตุการณ์โดยไม่เกิด error
- Mobile audio control test: viewport 390 x 844 ไม่มี horizontal overflow และปุ่มเสียงย่อเป็นไอคอน 47 x 40 px
- Browser console: ไม่พบ error หรือ warning ตลอดการทดสอบระบบเสียง
